## ✨ Features
- Responsive design for mobile, tablet and desktop
- White / black / green sections with a one-click **invert switch** (dark ⇄ light)
- Theme choice is remembered between visits
- Sections: About, Education, Skills, Experience, Services, Projects, Achievements, Contact
- Project filters: AI Agents & RAG, Flutter, Web

## 📂 Featured Projects
- 🤖 **Talenta** — AI recruitment assistant (MCP, memory, RAG, LangGraph)
- 🍽️ **MealPlan** — Flutter meal-planning app with calendar and favorites
- 🕯️ **Candila** — Responsive landing page for a candle brand

## 🛠️ Tech Stack
React 19 · TypeScript · Tailwind CSS 4 · Vite · Lucide Icons

## 🗂️ Project Structure
```
src/
├── components/   # Navbar, Hero, About, Education, Skills, Experience,
│                 # Services, Projects, Achievements, Contact, Footer
├── data.ts       # Projects, services, achievements & experience content
├── types.ts      # TypeScript types
├── index.css     # Theme (white / black / green) and animations
└── App.tsx       # App shell and theme switch
public/assets/    # Project images
```

## 🚀 Run locally
```bash
git clone https://github.com/ShahdmohamedFarouk11/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev
```
Then open http://localhost:3000

## 📦 Build
```bash
npm run build
npm run preview
```
